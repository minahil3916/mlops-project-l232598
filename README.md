# MLOps Project - l232598

This project demonstrates a basic MLOps version control workflow using Git, GitHub, and Visual Studio Code.

## Project Structure

- `data/` - Raw dataset
- `src/` - Python training scripts
- `model/` - Trained model artifacts
- `requirements.txt` - Python dependencies
- `.gitignore` - Files excluded from Git

## Installation

```bash
pip install -r requirements.txt
